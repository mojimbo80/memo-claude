## How to Use These Rules

- Reference these guidelines during code review
- Claude Code will check these rules when reviewing your code
- Update rules as your team's best practices evolve
- Document exceptions with clear reasoning

## Quick Checklist

Before submitting code:
- [ ] TypeScript strict mode compliant
- [ ] React hooks used correctly
- [ ] No console errors/warnings
- [ ] Tests written for new functionality
- [ ] Performance profiled (if relevant)
- [ ] Security checklist reviewed
- [ ] Code follows style guidelines
